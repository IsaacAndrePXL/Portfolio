01 — Opdracht

Van statisch naar dynamisch.

Voor het examen scripting was de uitdaging om een simpele statische website om te vormen tot een volledig functionele, dynamische webshop-ervaring voor een fictieve Italiaanse take-away.

De focus lag niet alleen op het visuele aspect of de styling, maar vooral op de complexe logica achter de schermen: hoe ga je om met externe data, hoe onthoudt een browser wat er in een winkelmandje zit als je navigeert, en hoe bereken je accuraat prijzen met wisselende extra opties?

02 — Aanpak

Modulaire opbouw en state management.

In plaats van gerechten hard te coderen in de HTML, wordt alle informatie (prijzen, ingrediënten, afbeeldingen, opties) via de fetch-API ingeladen uit een centraal JSON-bestand. Dit maakt de website schaalbaar en makkelijk aanpasbaar.

Een groot aandachtspunt was de winkelwagen logica. Er werd een uniek cartId systeem ontwikkeld. Hierdoor kan de code perfect onderscheid maken tussen bijvoorbeeld een standaard "Pizza Margherita" en een "Pizza Margherita met extra kaas", en worden deze netjes als aparte regels in de localStorage bewaard.

03 — Techniek

De motor onder de motorkap.

Om een soepele Single Page Application (SPA) feel te creëren, is er puur gebruik gemaakt van moderne Vanilla JavaScript (ES6+), zonder zware frameworks.

Local Storage

Persistente data · Cart Management

Fetch API

Asynchroon · JSON Data Parsing

DOM Manipulatie

Real-time filtering · Modals

Algoritmes

Prijsberekeningen · Sorteren

04 — Resultaat

Een complete bestelervaring.

Het eindresultaat is een vloeiende, interactieve website. Gebruikers kunnen live filteren op dieetvoorkeuren, sorteren op prijs, en via interactieve pop-ups (modals) hun gerechten personaliseren waarbij de prijs direct realtime mee-verandert.

Extra features zoals een willekeurig "Gerecht van de dag", een werkend kortingssysteem (met validatie) en zelfs verborgen 'Easter Eggs' (typ maar eens "honger" op het toetsenbord) maken het project helemaal af.
